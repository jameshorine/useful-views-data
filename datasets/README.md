# Catalogue

Everything in this repository: the datasets, full
[useful-views](https://jameshorine.github.io/useful-views/) projects on real
data, and the examples that `useful-views example` downloads. Each one's
catalog, generated by useful-views from its records, lists every view, the
recipe and steps that make it, and its columns.

## Datasets

No data is committed for a dataset. Each project downloads its raw files from
the publisher, checks every file against the SHA-256 recorded in its
`SOURCES.md`, and builds its views on your machine.

| Dataset | Publisher and source | Release | Coverage | Views | Catalog | Download | Use |
|---|---|---|---|---|---|---|---|
| [`census-acs`](census-acs/) | U.S. Census Bureau, [American Community Survey](https://www.census.gov/programs-surveys/acs/data/summary-file.html), table-based Summary File | 2020-2024 5-year estimates | The nation, 52 states (with DC and Puerto Rico), 3,222 counties and 85,382 census tracts | 8: geographies, the meaning of every ACS variable, and six tables (population, sex by age, median household income, poverty, educational attainment, median home value) with estimates, margins of error and Census's special values decoded | [catalog](census-acs/useful-views/README.md) | about 570 MB | A shared base for students' analyses: each student adds their own recipes on top of its views |

## Using one

A dataset, from its folder (for example `datasets/census-acs`); its README
has the details:

```sh
uv sync                      # the exact tool versions in the project's uv.lock
python fetch_raw.py          # download the raw files from the publisher and check them
uv run useful-views sync     # build the views
uv run useful-views check    # expect: No problems found.
```

An example, anywhere:

```sh
useful-views example pwt     # downloads and checks every file into pwt-example/
cd pwt-example
useful-views sync
useful-views check
```

## Adding a dataset

1. Open a [New dataset issue](https://github.com/jameshorine/useful-views-data/issues/new?template=new-dataset.yml)
   and fill in the form. Then link it from [#23](https://github.com/jameshorine/useful-views-data/issues/23) with a comment, such as
   `census-acs: #26 (open: …)`.
2. Start a branch from the latest `dev`: `new-dataset/<name>`.
3. Make the project with `useful-views init datasets/<name>`, and give it a
   `pyproject.toml` and `uv.lock` (`uv init --bare`, then
   `uv add useful-views` and the libraries its steps use).
4. Download nothing into git. Copy the issue's Source block into the
   project's `sources.toml`, and write a script that fetches each raw file
   into `raw/` and checks its size and SHA-256.
5. Write its recipes, build with `useful-views sync`, then run
   `useful-views cookbook`, and commit the recipes and the records.
6. Add a row to the datasets table above, and open a pull request into `dev`
   that says `Closes #N`.
7. Once it's merged, add a **Delivered** comment to the issue (the pull
   request, the catalogue row, any known problems in the source data), and
   mark it `done` in its comment on [#23](https://github.com/jameshorine/useful-views-data/issues/23).

Before committing, check `git status`: nothing from `raw/` or `work/`, and
no `.parquet` file, should be listed.

To add or change an example, follow [`examples/README.md`](../examples/README.md).
