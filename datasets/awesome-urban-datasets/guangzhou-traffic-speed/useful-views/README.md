## guangzhou-traffic-speed.parquet

Every speed observation in the Urban Traffic Speed Dataset of Guangzhou, typed: one row per road segment and 10-minute window, with the window's date and start time.

- Recipe: `recipes/speeds/`
- Inputs: `raw/Data.zip`

Steps:

1. Check that the zip is the pinned Zenodo file (its SHA-256) and holds the expected files, and extract its three CSV tables into work/. (`01_extract_csvs.py`)
2. Check each table's header and read every column with a fixed type. Round speeds to their three decimals, removing float noise such as 44.483000000000004. Join in each window's date and start time, sort by segment and window, and check the dataset's known facts. (`02_type_and_join.py`)

| Column | Type |
|---|---|
| road_id | integer |
| day_id | integer |
| time_id | integer |
| window_start | datetime |
| speed | number |

## guangzhou-traffic-speed-segments.parquet

One row per road segment of the Guangzhou dataset: how many of its 8,784 ten-minute windows have a speed, and its lowest, mean and highest speed.

- Recipe: `recipes/segments/`
- Inputs: `useful-views/guangzhou-traffic-speed.parquet`

Steps:

1. Count each segment's observations and missing windows (of 61 days × 144 windows), and give its lowest, mean and highest speed. The mean is computed from exact sums, so it doesn't vary between runs. Check that the counts add up to the dataset's totals. (`01_summarize.py`)

| Column | Type |
|---|---|
| road_id | integer |
| observations | integer |
| missing_windows | integer |
| days_with_data | integer |
| min_speed | number |
| mean_speed | number |
| max_speed | number |
